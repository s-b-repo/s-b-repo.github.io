Dynamic Context Runtime: Bounded Attention over Unbounded History

Language models degrade as stale and superseded material piles up in their context. Making the window bigger does not fix it. This report describes a runtime that keeps history unbounded and attention bounded — storing everything as immutable spans and a typed provenance graph, then assembling a small working set each turn by solving a knapsack under an explicit token budget. It includes a zero-dependency Rust implementation and an ablation that names which mechanisms are actually carrying the result.

// how we publish

What a report from us contains

01

Numbers you can re-run

Every table and figure lists the command that produced it. The experiments run offline with no API key and no network, so a reader can reproduce or refute them in minutes rather than trusting a screenshot.

02

The source, not a description of it

The implementation behind each report is released. A claim about a system that nobody else can run is marketing, and we would rather be checked than believed.

03

Negative results kept in

Ablations that show a mechanism earning nothing stay in the paper. A results table with no losing rows usually means the experiment was designed after the conclusion.

04

Limits stated in the paper

Each report carries an explicit threats-to-validity section saying what its evidence cannot support — synthetic data, missing comparisons, measurement shortcuts. The caveats are not in the footnotes.
