// what it is

Credential-strength testing, in native Rust

Rustforce is a credential-testing toolkit for authorized password-policy assessment, covering FTP, SSH and Telnet. Written in Rust, each module compiles to a small, dependency-free native binary — the FTP module ships as the dftp binary.

It bundles the supporting utilities real testing needs — IP-range generation and proxy download/test helpers — so you can source and validate proxies and feed targets without stitching separate scripts together.

// capabilities

What it does

The brute-forcer and the plumbing around it, in one toolkit.

Concurrent testing

High-concurrency login testing against a target and credential list.

FTP · SSH · Telnet

Covers the three classic remote-access services where weak credentials still hide.

Proxy-aware

Download, test and rotate proxies so testing traffic isn’t coming from one address.

IP generation

Generate target ranges to feed the testers without extra tooling.

Native binaries

Each module compiles to one small static binary — no runtime, no dependencies.

Wordlist-driven

Point it at your credential lists and go.
