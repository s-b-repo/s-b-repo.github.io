// what it is

Give an AI real Office documents — safely

OnlyOffice MCP Server gives an AI assistant 77 async tools for working with genuine Office documents — .docx, .xlsx and .pptx — in the same OOXML format Microsoft Office and ONLYOFFICE use, so everything it produces opens natively across every major suite.

It is more than a writer: every mutating call is journaled to a per-document history you can query, diff and revert; an AI “virtual cursor” tracks the current paragraph, cell or slide across calls; and it renders pages to PNG so a model can visually verify its own work.

Because documents are a classic malware and prompt-injection vector, the server ships defence-in-depth: zip-bomb and XML-entity protection, path-traversal and sensitive-path blocking, macro/VBA detection, a format-conversion whitelist, deletion rate-limiting with an audit trail, and prompt-injection scanning that flags adversarial text the moment a document is read.

// capabilities

What it does

Seventy-seven tools across three formats, wrapped in a security layer built for untrusted files.

77 document tools

Create, read, append, edit and convert docx/xlsx/pptx — tables, images, charts, headers and footers, TOC, comments, backgrounds and more.

Version history & revert

Every change is journaled per document; query the history, see exactly what was removed, and revert to any snapshot.

Prompt-injection scanning

Reads scan document text for ten adversarial patterns and return content warnings instead of blindly trusting the file.

Document-borne-attack defence

Zip-bomb detection, XXE/billion-laughs blocking, ReDoS rejection, macro/VBA detection and a strict conversion whitelist.

Safe deletion

Soft-delete trash with restore, mass-deletion detection, rate limiting, sensitive-path blocking and an immutable audit log.

Native charts & preview

Bar, line, pie, scatter and area charts across all three formats, plus page-to-PNG rendering for AI visual verification.
