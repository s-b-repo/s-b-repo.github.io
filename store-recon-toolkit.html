// what it is

The scanning that ordinary tools skip

The toolkit is anchored by Quicmap, an asynchronous QUIC and HTTP/3 port scanner with banner grabbing. It finds the UDP-based, TLS-wrapped services that ordinary TCP scanners miss entirely — it negotiates ALPN, and for HTTP/3 it issues a real request and reads back the server headers.

Around it sit the supporting recon tools: Stalkroute for deep path tracing, worldroute for bulk host recon, and smfp for SMTP/FTP sweeps — the breadth an external-surface pass needs, in Rust and Python.

// capabilities

What it does

QUIC-first scanning, plus the breadth tools for an external pass.

QUIC / HTTP-3 scanning

Quicmap probes single ports, ranges or all 65,535 for QUIC and HTTP/3 services.

ALPN & H3 banners

Negotiates ALPN and, for HTTP/3, issues a real GET to read back server headers.

Deep path tracing

Stalkroute traces paths in more detail than a plain traceroute.

Bulk host recon

worldroute runs recon across many hosts at once.

SMTP/FTP sweeps

smfp sweeps mail and FTP services across a target set.

Machine-readable output

Quicmap exports results to JSON or text for the rest of your pipeline.
