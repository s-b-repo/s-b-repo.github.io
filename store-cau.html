// what it is

Fourteen detectors, every verdict explained

CAU reads every file once and runs fourteen detectors over it — hash and YARA matching, heuristics, native PE/ELF/Mach-O structure analysis, hidden-codepoint detection, and parsers for encoded/obfuscated payloads, LNK shortcuts, OLE macros, PDF and ISO lures. Every finding carries a labelled class and an ATT&CK technique, so a result explains itself.

It also scans the live process table and UEFI firmware, keeps an integrity-sealed quarantine vault, and emits CI exit codes plus SARIF, OCSF and JSON — so it drops into a CI pipeline or a security data lake as cleanly as it runs on a workstation.

// capabilities

What it does

Transparent by design — every detector names what it found and why.

Fourteen detectors

Hash, YARA, heuristics and more — each file is read once and run through all of them.

ATT&CK-mapped findings

Every verdict carries a labelled class and a MITRE ATT&CK technique, so results are explainable.

Static structure analysis

Own PE/ELF/Mach-O parsers flag packers, forged build records, RWX sections and other ‘built to hide’ signals.

Obfuscation & document lures

Peels encoded/obfuscated payloads and parses LNK, OLE macro, PDF and ISO lures.

Process & firmware scan

Scans the live process table for fileless/injected threats, and UEFI firmware for implants.

CI-ready output

SARIF, OCSF and JSON with CI exit codes, plus an integrity-sealed quarantine vault.
