// what it is

An AI pentest agent that stays inside the scope you signed for

OpenHack is a multi-agent AI assistant that plans and executes authorized security assessments — recon, exploitation, post-exploitation and reporting. It is a hardened fork based on the OpenCode coding agent, rebuilt around a safety and rules-of-engagement layer so the automation can never operate outside a scope you authorized in writing.

Rather than one monolithic model, OpenHack dispatches work to specialist subagents — recon, exploit, post-exploit, C3 and reporting — and routes each task to the one best suited to it. A council review can fan a single finding out to independent reviewer agents for a second opinion before it ever reaches the client report.

Every tool call passes a single runtime enforcement hook that checks the engagement scope and a hash-signed Rules-of-Engagement record before anything is allowed to execute. Findings are written with integrity hashes and uncertainty flags, and secrets are scrubbed automatically on the way out.

// capabilities

What it does

The capabilities below are drawn straight from the project — the safety harness is the point, not an afterthought.

Multi-agent architecture

Recon, exploit, post-exploit and reporting subagents coordinate through an orchestrator, each specialised for its phase of the engagement.

Signed Rules of Engagement

Hash-signed authorization fields with tamper detection; a single runtime hook blocks any tool call that falls outside the signed scope.

MCP tool integration

Bundles opt-in Model Context Protocol servers — recon, findings, reporting and more — all disabled by default until you explicitly enable them.

Integrity-checked findings

Findings carry HMAC integrity and uncertainty flags; secrets are scrubbed automatically before anything is stored, exported or shared.

MoE routing

Dispatches each task to the best-matching specialist and remembers what worked, so routing sharpens as the engagement runs.

Council review

Fan a finding out to independent reviewer agents for an adversarial second opinion before it lands in the report.
