// tools

The toolkit.

Every tool we publish is open source, and every one is listed here with the same three things spelled out: what it is, what it's capable of, and where its limits are. No overselling — a tool that quietly does less than its README implies is a liability on an engagement. The source is public; support, hardening and customisation are the paid part. Everything here is for authorized testing and defence only.

// offensive & recon

Reconnaissance & exploitation

Scanning, credential testing and exploitation — used only against systems you are authorized in writing to test.

Quicmap

Python · QUIC/HTTP3 scanner

An asynchronous QUIC and HTTP/3 port scanner with banner grabbing — reconnaissance for the UDP-based, TLS-wrapped transport that ordinary TCP scanners miss entirely.

  • QUIC / HTTP/3
  • ALPN & H3 headers
  • JSON · TXT output

Capabilities: probes single ports, ranges or all 65,535; negotiates ALPN; for HTTP/3 it issues a real GET and returns the server headers; for other QUIC services it grabs a generic banner. Concurrency and per-port timeout are tunable, and results export to JSON or text.

Limits QUIC/UDP only — it is not a general TCP or service scanner, and a silent host is reported closed. Needs Python 3 with aioquic and colorama (see requirements.txt). TLS certificates are not verified (recon, not validation). Read the full breakdown →

rustsploit

Rust · exploitation framework

A modular offensive-tooling framework for embedded and IoT targets — it began as a Rust rebuild of RouterSploit and has since grown into its own thing.

  • Modular exploits
  • Embedded / IoT
  • Bluetooth support

Capabilities: a framework of scanner, exploit and credential modules aimed at embedded devices, built in safe, fast Rust. Default builds include a Bluetooth module (BLE via btleplug).

Limits Research-grade and evolving — module coverage varies by target. Compiles with a heavy release profile (fat LTO), so a first build is slow. Strictly for authorized testing of devices you own or are contracted to assess. Read the full breakdown →

rustforce

Rust · credential testing

A fast, concurrent FTP brute-forcer (the dftp binary) for authorized credential-strength testing.

  • Concurrent FTP
  • Wordlist-driven
  • Single static binary

Capabilities: high-concurrency FTP login testing against a target and credential list, compiled to one small native binary with no runtime dependencies.

Limits FTP only today, and it drops straight into scan mode with no --help usage screen — read the repo's usage notes first. Brute-forcing any service you are not explicitly authorized to test is illegal; this is for sanctioned password-policy checks only. Read the full breakdown →

OpenHack

Bun / TypeScript · AI agent

An AI-powered security-assessment agent — an OpenCode fork wired for authorized penetration testing, driven from a terminal UI.

  • Agentic TUI
  • MCP tool servers
  • Multi-provider LLM

Capabilities: a 45-package monorepo exposing a tui, headless run, MCP and ACP integrations, provider/auth management and attachable tool servers — an LLM-steered assistant for recon, triage and assessment workflows.

Limits Needs the Bun runtime and your own model-provider API keys; the bundled MCP security servers are opt-in and bring their own toolchains. It assists a tester — it does not replace human judgement or written authorization, and an LLM can be confidently wrong. Read the full breakdown →

// command & control

Red-team infrastructure

Adversary-emulation infrastructure for sanctioned red-team engagements.

ArcticFox-C3

Rust · command-and-control

A command-and-control framework for red-team operations — a multi-crate Rust workspace covering the whole chain from agent to operator console.

  • Agent · API · dashboard
  • io_uring transport
  • MCP + scanner

Capabilities: builds a family of binaries — agent, API server, the c3 operator dashboard, control plane, bindshell, a scanner and an MCP bridge — with an io_uring-based transport. Adversary emulation to test detection and response.

Limits This is offensive infrastructure: run it only inside a red-team engagement that is authorized in writing, on infrastructure you control. Research-grade — expect to read the code. Standing C2 up against systems without authorization is a crime. Read the full breakdown →

// blue team & detection

Detection, hardening & monitoring

The defensive half of the kit — detect malware, stand up a monitoring stack, and harden the endpoints.

CAU

Go · malware-detection engine

“Certs Are Useless” — a transparent, open-source malware-detection engine. Fourteen detectors read every file once, and every finding is explained with a labelled class and an ATT&CK technique.

  • 14 detectors · ATT&CK
  • SARIF · OCSF · JSON
  • YARA · static · heuristics

Capabilities: hash and YARA matching, heuristics, native PE/ELF/Mach-O structure analysis, hidden-codepoint and encoded/obfuscated-payload detection, and parsers for LNK, OLE macros, PDF and ISO lures. It also scans the live process table and UEFI firmware, keeps an integrity-sealed quarantine vault, and emits CI exit codes and SARIF/OCSF/JSON for a security lake.

Limits A scanning and detection engine, not a real-time kernel EDR on its own (kernel enforcement lives in the separate cau-kernel sensor). Detection quality tracks its signatures and rules, so keep them current; heuristic verdicts are suspicion, not proof. Read the full breakdown →

Elastacat

Python · stack installer

An automated installer for an Elastic + TheHive/Cortex stack — the log-pipeline and case-management side of a working detection setup.

  • Elastic
  • TheHive · Cortex
  • One-shot setup

Capabilities: installs and wires Java, Elasticsearch and the TheHive/Cortex case-management layer so you get an ingestion-and-triage pipeline without assembling it by hand.

Limits It is a provisioning script, not a running service: it targets Debian 12 specifically and must run as root. Run it on a fresh host you intend to dedicate to the stack — review it before pointing it at anything else. Read the full breakdown →

Dockerised Wazuh Installer

Python · stack installer

Automated, Docker-based deployment of Wazuh — the open-source XDR/SIEM — with separate paths for Debian and Ubuntu.

  • Wazuh XDR/SIEM
  • Dockerised
  • Debian & Ubuntu

Capabilities: drives the full Wazuh-in-Docker install end to end, so a host goes from bare to a working Wazuh manager and dashboard with the steps scripted and repeatable.

Limits A provisioning script: needs Docker and root on a supported Debian/Ubuntu host, and does not manage the stack after install. Size the host for Wazuh's requirements first. Read the full breakdown →

p2soc — SOC Video Wall

Python + GTK · kiosk appliance

Turns a Raspberry Pi 5 into a Security-Operations-Centre video wall: an HDMI display that boots into a taskbar-less 2×2 grid of auto-logging-in dashboards.

  • Wazuh · Zabbix · Grafana
  • Vault-backed logins
  • autossh · VPN · self-heal

Capabilities: four draggable browser panels, each auto-logging-in from a local Vaultwarden secrets vault and re-logging-in on timeout; panels can reach remote networks over an autossh jump tunnel or a supervised Fortinet/OpenVPN/WireGuard link. It self-heals crashed panels and is configured entirely on-screen — no SSH, no file editing. An interactive setup.py wizard writes the config.

Limits A GUI kiosk appliance: it expects its target — a Raspberry Pi 5 (the reference board) or a Linux desktop with GTK/PyGObject and a display — so it does not run headless. Credentials are only as safe as the vault passphrase you set. Read the full breakdown →

Windows Hardening

PowerShell · baseline script

A PowerShell script that applies a security-hardening baseline to a Windows host.

  • Windows baseline
  • One script
  • Auditable

Capabilities: applies a set of defensive configuration changes in one pass, with the whole baseline visible in a single readable script you can diff and adapt.

Limits Windows only, and must run elevated (Administrator). Hardening can break line-of-business software — read it, test on a non-production machine, and have a rollback before applying it to real endpoints. Read the full breakdown →

// infrastructure & integration

Performance & integration

Supporting engines that aren't security tools themselves but earn their place in the kit.

Peregrine

Rust · inference engine

“The fastest bird” — a Rust Mixture-of-Experts inference engine that drives CPU, GPU, RAM and SSD concurrently with io_uring.

  • MoE inference
  • io_uring I/O
  • CPU default · CUDA optional

Capabilities: an 11-crate workspace that runs large Mixture-of-Experts models by overlapping compute and storage I/O, so it can serve models larger than RAM. The local-AI engine behind our AI-assisted tooling.

Limits A performance/ML engine, not a security tool in itself. CUDA is an off-by-default feature — the default build is CPU-only and GPU acceleration needs the NVIDIA toolchain. Research-grade and fast-moving. Read the full breakdown →

OnlyOffice MCP Server

Python · MCP server

A Model Context Protocol server that lets an AI agent read and write Office documents — Word, Excel and PowerPoint — through a clean tool interface.

  • docx · xlsx · pptx
  • MCP over stdio
  • Report automation

Capabilities: exposes document tools over MCP (built on python-docx, openpyxl and python-pptx), so an agent can generate and edit deliverables such as assessment reports instead of hand-formatting them.

Limits Not a standalone app — it is a stdio MCP server you attach to an MCP-capable client. It pins the mcp 1.x API; it is a document-automation integration, not a security scanner. Read the full breakdown →

Guides & references (not programs)

Two of our public repositories are documentation, not software — included here so the distinction is explicit.

cardsz

Reference · RFID/NFC guide

A comprehensive write-up on how RFID and NFC access cards are assessed and cloned with a Proxmark3 — Mifare Classic, HID Prox, EM4100, iCLASS, NTAG, DESFire and more.

Not a tool It is a Markdown guide — there is nothing to install or run. For educational and authorized physical-security assessment only; cloning credentials you don't own or aren't permitted to test is illegal. Read the full breakdown →

advanced-shodan-requests

Reference · Shodan queries

A curated reference of advanced Shodan search queries for finding exposed services and devices — with screenshots of the kinds of results each one surfaces.

Not a tool It is a query reference, not a program — there is nothing to run. Use it to understand your own external exposure; investigate only systems you are authorized to assess. Read the full breakdown →
