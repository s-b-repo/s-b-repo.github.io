// what it is

RouterSploit, rebuilt in Rust — and grown past it

Rustsploit is a modular offensive-security framework for embedded and IoT devices. It organises scanner, exploit and credential modules behind a single workflow, rebuilt in safe, fast Rust so the tooling is memory-safe and ships as native binaries.

It started as a Rust rewrite of RouterSploit and has since outgrown it, gaining its own module set and capabilities — including a Bluetooth (BLE) module in default builds. It is the framework our commissioned custom-module work is written against.

// capabilities

What it does

A framework, not a one-shot script — modules share one interface so new targets slot in.

Modular architecture

Scanner, exploit and credential modules share one interface, so new targets slot in without reworking the framework.

Embedded & IoT focus

Aimed at the routers, cameras and embedded devices that rarely get patched — the soft underbelly of most networks.

Memory-safe Rust

Rewritten from the Python original into Rust: no interpreter, native single-binary builds, memory-safety by construction.

Bluetooth support

Default builds include a BLE module (btleplug) for reaching wireless embedded targets.

Credential testing

Modules for testing default and weak credentials against exposed services.

Built to extend

The framework our commissioned modules are written against — your targets, your rules of engagement, you keep the source.
