// what it is

A repeatable Wazuh install, scripted end to end

Wazuh is a powerful open-source XDR/SIEM, but standing it up by hand is fiddly and easy to get subtly wrong. This installer scripts the whole Docker-based deployment, so a bare host becomes a working Wazuh manager and dashboard with the steps codified and repeatable.

Separate, tested paths for Debian and Ubuntu handle the package and Docker differences between the two, so the same result lands on either.
