// what it is

A self-healing SOC wall out of a single-board computer

p2soc boots a Raspberry Pi 5 straight into a taskbar-less desktop showing four draggable browser windows in a 2×2 grid. Each panel points at a different dashboard — Wazuh, Zabbix, Grafana or any URL — auto-logs-in from a local Vaultwarden secrets vault, and re-logs-in when the session times out.

Panels can reach remote networks over an autossh jump tunnel or a supervised VPN (Fortinet SSL-VPN, OpenVPN or WireGuard), with health checks and auto-reconnect. It self-heals crashed panels, respawns the browser, and is configured entirely on-screen — no SSH, no file editing — via an interactive setup wizard.

// capabilities

What it does

Boots to a wall, logs itself in, and keeps itself up.

2×2 kiosk wall

Four draggable browser panels in a taskbar-less grid, each pointed at its own dashboard URL.

Auto-login from vault

Credentials come from a local Vaultwarden vault, answered in memory, with re-login on timeout.

autossh jump tunnel

Panels on remote networks are reached through a persistent SSH jump tunnel.

Supervised VPN

Fortinet SSL-VPN, OpenVPN or WireGuard with health checks and auto-reconnect.

Self-healing

Crashed panels show a status card and retry with backoff; the browser respawns on its own.

On-screen config

Point any panel at any URL from the on-screen menu — no SSH, no file editing.
